# GraphiXSite

Portfolio site for Shivani Sharma, styled as a desktop: projects are draggable icons, the dock holds Premiere Pro, Photoshop and Illustrator.

## Editing content
Everything lives in `index.html`, between `EDIT HER CONTENT HERE` and `END OF CONTENT`:
- `OWNER`: name, email, Instagram, about text, skills, CV, interests, gallery images
- `PROJECTS`: title, client, type, description, desktop position (`x`, `y` in %), `thumb`, `images`, optional `video` embed URL
- `ALERTS`: the joke pop ups shown by the dock apps

Put images in `img/`. The blurred background is `img/wallpaper.jpg`.
